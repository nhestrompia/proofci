repository ID `1428210914`, destination repository ID `14747598`, head
`0fff552b9e2516c8b15a25f23ffc697357c1b86f`, and base
`89a34a44b7a6a5311dc84f3b8a1b8b45c0905aea`. The test signed a local webhook,

through isolated dispatch. A temporary fixture baseline targeted `package.json`.
The authoritative result was blocked with `unsupported_semantics` and zero
model calls. GitHub App installation authorization was simulated for this test;
it does not establish merge-check enforcement. The PR may later change or close.

The educational fork fixture commits a proof containing checks of dummy host,
credential and other-repository cache paths, credential environment variables,
and a public TCP endpoint. A positive control checks the endpoint from the host.
The proof intentionally ends with a randomly assembled test marker after the
checks. A blocked `proof_failed` report containing that marker establishes that
the construction sandbox reached the end of the fixture. The separate fixed
worker probe reports denials for dummy host, credentials, workspace, cross-repository
cache, socket and network checks. That probe runs in its own fixed guest; its
output is not generated by the fork.
